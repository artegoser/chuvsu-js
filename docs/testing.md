# Проверка расписания v5

Эталонные JSON составляются и изменяются только вручную. Генератора эталонов в
репозитории нет. Каждый пример мал: исходный HTML можно прочитать целиком и
сопоставить с ожидаемыми полями в одном ревью.

Полностраничный корпус из 34 расписаний групп, 4 преподавателей и 4 аудиторий —
это набор реальных входных данных. Он проверяет, что парсер не падает, создает
валидные наблюдения и находит общие пары между разными страницами. Корпус не
выдается за вручную подтвержденный эталон всех значений.

Точечные примеры проверяют семестр, сессию, экзамены, консультации, подгруппы,
ДОТ, замены, преподавателя «вместо», переносы и отсутствие данных. Доменные
тесты проверяют ID, неоднозначность, объединение проекций, применение изменений
и календарное раскрытие. `pnpm test:coverage` требует для ядра расписания не
меньше 95% строк, 94% функций и 80% ветвей.

Live-тест сравнивает парсер с текущими страницами портала, но не заменяет
зафиксированные HTML и ручные эталоны.
